## How to navigate

Open `index.html` in a browser or visit the GitHub Pages version. Use the top menu for the 9 separate navigation pages, plus the 11 full step-specific research pages. On the Journey page, search by term or filter steps by Build, Data, Validation and Writing. Print the Professor guide from your browser if desired.

## File structure

- 20 HTML pages: nine navigation sections and 11 dated individual step reports.
- `assets/styles.css`: responsive color-coded design and print styles, no remote fonts or images.
- `assets/site.js`: small interactive filtering, nav labeling, print support. Page text stays readable without JavaScript (except filtering).
- All evidence links lead to the original public GitHub source paths. Sensitive or restricted research records are not embedded.

## Versioning rules

This folder is an **immutable presentation snapshot** linked to the November 13 research journal. Later improvements must be saved to a new folder with actual date/time, never replace this edition or an original research file. Site files and research scripts are distinct; the portal does not alter experimental outcomes.
