# Public-data sharing safeguards

This project uses official third-party tourism indicators. The project has a complete local JSON export and processed monthly visitor/spending panels, but those **have not been newly uploaded in this public GitHub organization step**.

Before committing full derived or source-export tables, verify and retain the source provider's current citation and redistribution terms. Do not assume that a public download or API equals permission to republish.

Also inspect `data/raw/` already present on the default branch for existing historical files, including whether each item's redistribution is authorized. Protect API keys and session credentials. Use an approved private storage location if required.

See [official source links and caveats](../docs/research/SOURCES_AND_REUSE.md).
