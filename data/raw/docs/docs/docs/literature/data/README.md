# Data Folder

## raw/

Contains original downloaded datasets.

Files in this folder must NEVER be manually edited.

Examples:

- foreign_spending_raw.csv
- foreign_visitors_raw.csv
- busan_attractions_raw.csv
- busan_restaurants_raw.csv
- recommendation_audit_raw.csv

## processed/

Contains cleaned and merged datasets created from the raw data.

Examples:

- district_month_panel.csv
- poi_master.csv
- recommendation_exposure.csv

## Rule

RAW DATA = ORIGINAL

PROCESSED DATA = CLEANED / TRANSFORMED

Never overwrite the original raw datasets.
