## Safe synchronization sequence

1. Obtain the referenced ZIP and newest Mac project as separate copies, outside
   the Git checkout. Preserve their original filenames and compute SHA-256 hashes.
2. Compare manifests with this branch; inspect code diffs and run tests before
   choosing versions. Do not use a blanket overwrite/recursive merge.
3. Review dataset permissions and source receipts; place private inputs under
   ignored `data/private/`. Do not force-add them into Git.
4. Recover and run the original RQ1/RQ2/RQ3/accessibility scripts with frozen
   queries, units, parameters, station coordinates and environment versions.
5. Save new outputs separately; compare with archived tables and document
   numerical differences before updating any established result.
6. Review this pull request; merge only after professor/researcher review.
